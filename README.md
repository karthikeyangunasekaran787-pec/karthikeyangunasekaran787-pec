## 🚀 Featured Projects

### 1. EcoSense – IoT-Based Air Quality Monitoring System

An ESP32-based air-quality monitoring prototype developed as a Microprocessor and Microcontroller lab mini project.

**Key Features**
- Gas-level monitoring using an MQ gas sensor
- Temperature and humidity monitoring using DHT22
- Real-time readings on an OLED display
- LED and buzzer alerts for high gas-level conditions
- Wokwi-based circuit simulation and testing

**Technologies:** ESP32, Embedded C/C++, Arduino Framework, Wokwi

🔗 [View Project on GitHub](https://github.com/karthikeyangunasekaran787-pec/EcoSense-Air-Quality-Monitor)

### 2. AarogyaLink – Rural Healthcare Referral and Tracking Platform

A web-based platform designed to improve coordination between patients, health workers, doctors and hospitals.

**Key Project Areas**
- Role-based user access
- Digital patient health cards
- QR-based health card verification
- Healthcare referral tracking
- Patient and healthcare workflow management

**Technologies:** React, TypeScript, Convex and Convex Auth (as documented in the repository)

🔗 [GitHub Repository](https://github.com/karthikeyangunasekaran787-pec/aarogyalink)

🌐 [Live Project](https://aarogyalink.freebuff.app/)
